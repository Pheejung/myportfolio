## 💻 프로젝트 소개

이 프로젝트는 저의 기술 스택, 경험, 그리고 프로젝트들을 보여주기 위해 만들어진 개인 포트폴리오 웹사이트입니다. 방문자들에게 즐거운 경험을 제공하기 위해 인터랙티브한 요소와 동적인 애니메이션을 활용했습니다.

## 🛠️ 주요 기술 스택

- **React**: 컴포넌트 기반의 UI 개발
- **TypeScript**: 타입 안정성을 통한 코드 품질 향상
- **Vite**: 빠르고 효율적인 개발 환경
- **Tailwind CSS**: 신속한 스타일링 및 반응형 디자인
- **GSAP (GreenSock Animation Platform)**: 정교하고 부드러운 스크롤 애니메이션 구현
- **gh-pages**: GitHub Pages를 이용한 간편한 배포

## 🚀 로컬에서 실행하기

**사전 준비:** [Node.js](https://nodejs.org/)가 설치되어 있어야 합니다.

1.  **저장소 복제:**

    ```bash
    git clone https://github.com/Pheejung/myportfolio.git
    cd myportfolio
    ```

2.  **의존성 설치:**

    ```bash
    npm install
    ```

3.  **개발 서버 실행:**

    ```bash
    npm run dev
    ```

4.  브라우저에서 `http://localhost:3000` 주소로 접속하여 확인합니다.
